Your first dependency

Start in a Rust project.

Use Rust 1.96 or newer. Choose a pinned Git revision, or download the same source and use a local path dependency. Cargo resolves the crate dependencies; the source archive does not bundle a Rust toolchain.

A first picker · actual library API

use tuilith::pick::Filter;

let names = ["Terminal UI", "Database"];
let mut filter = Filter::new();
filter.push('t');
filter.push('u');
filter.refilter(names.iter().copied());
assert_eq!(filter.selected().unwrap().index, 0);

Keep dependency choices explicit.

FeatureWhat it addsDependency behavior
backgroundTerminal light/dark detectionUses terminal-colorsaurus
document-treeFoldable JSON document treeUses serde_json with preserve_order
os-appearanceDesktop appearance signalsImplies background; may run OS commands

Default features enable all three. Use default-features = false to begin with the core modules, then opt in to the extra behavior your application needs.

Know the pieces you use

Component origins stay close to the code.

Each component declares its lineage: original, inspired, wrapper or tracked fork. The generated provenance record accompanies the source so you can inspect those declarations.

CI checks the declarations against the repository and runs cargo-vet and cargo-deny policies. These checks include recorded trust and exemptions; they are not a claim that every dependency has received an independent audit.
